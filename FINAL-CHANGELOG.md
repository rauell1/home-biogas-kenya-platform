# Final consolidation changelog

## Foundation selected

A2 was retained as the main production foundation because it contains the stronger public experience, multilingual architecture, project workflow, admin breadth and verification model.

## Learnings incorporated from A and B

- A's editorial restraint, chapter framing, material palette and technical typography
- B's stronger authentication direction and production-oriented server architecture
- B1 used only to understand the intended visual concept and interaction language

## Removed from earlier prototypes

- Vite single-page architecture
- fake email-pattern authentication
- hard-coded dashboard data
- emoji application cards
- unsupported homepage statistics
- inactive forms
- arbitrary gas estimates without quantity inputs
- small generic project cards as the main portfolio experience
- external company claims and imagery

## Added or consolidated

- Next.js App Router
- locale routing
- interactive digester
- continuous gas-distribution scene
- project explorer
- engineering configurator
- assessment and lead workflow
- source-verification records
- media-rights review
- role-based admin navigation
- audit logging
- Neon/Drizzle schema and migration
- Better Auth API foundation
- invitation-only staff onboarding
- production setup documentation
